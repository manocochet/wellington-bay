# Wellington Bay

Site de la Ville de Wellington Bay, exporté de Claude Design.

Site statique : chaque page `*.dc.html` est rendue dans le navigateur par `support.js`
(React chargé depuis unpkg). `index.html` redirige vers `Accueil.dc.html`.

Pour tester en local, servir le dossier avec un serveur HTTP, par exemple :

    python -m http.server 8000
